راهنمای انتشار سایت

۱) فایل ZIP را از حالت فشرده خارج کنید.
۲) وارد مخزن GitHub خود شوید.
۳) فایل‌های index.html، style.css و script.js را در صفحه اصلی مخزن بارگذاری کنید.
۴) از Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
۵) Branch را روی main و پوشه را روی /(root) قرار دهید و Save را بزنید.
۶) پس از چند دقیقه، نشانی سایت در همان بخش نمایش داده می‌شود.

نکته:
- شماره تماس 09000000000 نمونه است و باید با شماره خودتان عوض شود.
- نام، توضیحات، شهرها و خدمات داخل index.html قابل ویرایش هستند.
- ظاهر سایت برای موبایل و تبلت هم واکنش‌گراست.
- فونت از Google Fonts بارگذاری می‌شود؛ در صورت نبود اینترنت از فونت جایگزین استفاده خواهد شد.
